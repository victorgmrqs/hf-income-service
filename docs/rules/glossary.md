# Glossário

| Termo | Definição |
|-------|-----------|
| Competência | Período de referência no formato `YYYY-MM` — diferente da data do lançamento |
| Teto global | Limite máximo de gastos totais do mês definido pelo usuário |
| Receita recorrente | Receita propagada automaticamente todo mês; editável a partir da competência atual |
| Saldo projetado | Saldo atual descontadas as despesas certas ainda não pagas no mês |
| Meta de redução | Valor absoluto que o usuário se compromete a não ultrapassar em uma categoria |
| Despesa comprometida | Conta a pagar com `status = PENDING` dentro da competência — já representa saída certa |
| Auto-ajuste | Mecanismo que reduz progressivamente o teto global com base no gasto real do mês anterior |
